# 제주 여행 플래너

제주도 맛집·카페·명소를 권역별로 모아 보고, 마음에 드는 곳을 담아 나만의 여행 목록을 만드는 모바일 우선 정적 웹페이지입니다.

- `jeju-trip-planner.html` — 플래너 본체. 스타일과 스크립트, 장소 데이터가 모두 이 파일 안에 있습니다
- `theme.js` — 다크/라이트 모드 전환
- `_redirects` — Cloudflare Pages에서 루트(`/`)로 접속했을 때 플래너를 보여 주기 위한 설정

## 기능

- **검색** — 이름·주소·설명·추천 메뉴·방문 팁·카테고리·권역을 전문 검색
- **필터** — 카테고리(맛집/카페/명소) × 권역(제주시/애월·한림/조천·구좌/성산·표선/서귀포·중문) 조합
- **보기 전환** — 카드형/리스트형, 선택은 다음 방문에도 유지
- **담기** — 마음에 드는 장소를 담아 권역별로 묶어 확인. localStorage에 저장돼 재방문 시에도 유지
- **삭제** — 목록에서 감추기. 원본 데이터는 그대로이며 되돌리기로 언제든 복원

## 장소 추가·수정

`jeju-trip-planner.html` 하단 스크립트의 `PLACES` 배열에 항목을 넣으면 됩니다.

```js
{
  id: "unique-id",          // 다른 항목과 겹치지 않는 값
  name: "장소 이름",
  category: "맛집",          // 맛집 | 카페 | 명소
  region: "jeju-city",      // REGIONS의 id 중 하나
  address: "제주시 ...",
  summary: "한 줄 설명",
  highlight: "추천 메뉴 또는 볼거리",
  hours: "09:00~18:00",
  price: "1만원대",
  tip: "방문 팁",
}
```

권역을 늘리려면 같은 스크립트의 `REGIONS` 배열에 `{ id, name }`을 추가하세요.

## 실행과 배포

빌드 도구가 필요 없습니다. 파일을 브라우저로 열면 그대로 동작합니다.

Cloudflare Pages는 이 저장소를 연결하고 빌드 명령은 비운 채 출력 디렉터리를 루트(`/`)로 지정하면 됩니다.

## 참고

장소의 영업시간·가격대는 일반적으로 알려진 값이며 변동될 수 있습니다. 각 카드의 카카오맵 링크에서 방문 전에 확인하세요.
